# Models and data files

Every file the product loads that is not code. The checksum list is `models/SHA256SUMS` (written by
`scripts/write_sums.py`); the files under `src/extract/guard/data/` are not in git and are rebuilt byte for byte
by `scripts/build_dictionaries.py` (it needs wordfreq, a development dependency).

The word lists are derived (by scripts/build_dictionaries.py) from wordfreq by Robyn Speer (https://github.com/rspeer/wordfreq), whose data is licensed CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/); the derived files keep that licence. wordfreq's data includes Google Books Ngrams (http://books.google.com/ngrams), the Leeds Internet Corpus, Wikipedia, ParaCrawl, OPUS OpenSubtitles 2018 (data from OpenSubtitles, http://www.opensubtitles.org/) and the SUBTLEX word lists created by Marc Brysbaert et al., which are freely available data (http://crr.ugent.be/programs-data/subtitle-frequencies). No text of any benchmark document is in these files.
